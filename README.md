# City Arc

Scroll-driven orbit of city skyline cards along a circular arc. Built with Next.js, GSAP, and Lenis.

**[Live demo →](https://images-sweep-on-orbit.vercel.app/)**

## What it does

Eleven city plates ride a large circle as you scroll. The first card closes onto the arc; the rest travel the orbit until the last one stops, straightens, and opens across the frame.

Cities: Tehran, Tokyo, Paris, Dubai, Rome, Istanbul, Singapore, London, Barcelona, Hong Kong, New York.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [GSAP](https://gsap.com) for scroll-linked motion
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scrolling
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```
